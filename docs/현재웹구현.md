# 현재 웹 구현 상태

기존 `00_이식기준.md`는 이전 역분석 단계의 향후 설계 목표입니다. 실제 이번 구현은 README의 보존 범위 및 한계를 기준으로 합니다. 특히 중복 선택, 소유자별 완전한 상태 분리, 대체 스킬 선택은 아직 구현하지 않았습니다. 일반 2인 전투의 모든 캐릭터 블록을 먼저 보존하여 실행하는 단계입니다.

분석 문서의 캐릭터별 기술 수치와 원본 코드 근거는 계속 유효합니다. 웹 실행부와 엔트리 엔진을 별도로 구현한 만큼, 자동 실행 검사 통과와 원작 대비 완전한 판정 동등성은 구분합니다.


## 온라인 대전 추가

로컬 모드 외에 방 코드 기반 온라인 대전을 추가했습니다. 블라인드 선택, 같은 빌드 검사, 공통 난수 시드, 프레임 입력 동기화, 직접 연결과 서버 중계, 재접속을 지원합니다. 전투 수치·그림·스킬 블록은 그대로 유지합니다. 중복 선택과 대체 스킬, 예측·롤백은 아직 구현하지 않았습니다. Vercel 배포 후에는 공유 방 상태를 위한 Redis 연결이 필요합니다. 자세한 설정과 검증 한계는 README를 기준으로 합니다.
