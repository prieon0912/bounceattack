바운스어택 추가 밸런스 패치 — 5개 캐릭터
모든 변경은 1P·2P에 동일하게 적용한다. 명시하지 않은 피해량·스킬 효과·애니메이션은 유지한다.

1. 칸
- 평타·R의 실제 주먹 판정에 수평 1좌표, 수직 2좌표의 여유를 추가한다.
- 주먹 그림의 크기와 애니메이션 궤적은 변경하지 않는다.
- 기존 공격 유효 시간, 손별·공격 구간별 최대 타격 횟수는 유지한다.
- 피해량·MP 소모·후딜 초기화·궁극기는 유지한다.
- 이동 경로를 이어 검사하는 추가 판정은 이번에 넣지 않는다.

2. 가드
- 평타 피해량: 9 → 10.
- 평타 적중 시 속박 지속시간을 실제 0.5초(60Hz 기준 30틱)로 설정한다. (기존 속박 변수의 숫자 0.5를 그대로 사용하는 뜻이 아니다.)
- 평타 사거리와 단발 거리 검사 방식, R·궁극기·생존 패시브는 유지한다.

3. 워트
- 평타 사거리 1.5배, 궁극기 딜레이 0.8배.
- 평타·궁극기의 피해량과 MP 소모 유지. 사거리 증가를 위해 그림 크기나 명중 판정을 확대하지 않는다.

4. 엔릴
- 평타 사거리 1.1배, 평타 피해량 4 → 5.
- 기존 밀치기 효과와 R·궁극기 유지. 그림 크기나 명중 판정 확대 없음.

5. 캐논
- 평타 사거리 1.2배.
- 특수 공격의 타겟 가능 거리 제한 삭제(타겟 획득의 거리 제한만, 실제 충돌·적중 조건 유지).
- 특수 공격 피해량 7 → 6.
- P스킬 적중 시에도 파편 1개 획득.
- 연속 발사 시 각 탄을 생성하는 순간 캐논의 현재 위치와 발사구 위치를 기준으로 발사. 이미 발사된 탄은 따라가지 않음. 타겟 좌표 갱신·유도는 변경하지 않음.
- 그림 크기나 명중 판정 확대 없음.

적용 메모 (tools/balance-patch.cjs)
- 칸: reach_something에 여유 인자(1, 2)를 추가하고 runtime.js가 정수 좌표 오프셋으로 추가 검사.
- 가드: 속박 변수는 틱당 0.02 감소하고 설정한 틱에도 한 번 줄어들므로 30틱 = 0.62.
- 워트: 두 물결의 시작 위치·속도·감속 1.5배(지속 시간 유지). 궁 대기 30 → 24틱, 기 모으기 연출 3×10 → 3×8.
- 엔릴: 바람 속도 7 → 7.7(14틱 유지). 바람은 부채 위치에서 생성되므로 이동 거리 기준 1.1배.
- 캐논: 발사구 5 → 6, 속도 6 → 7.2, 감속 0.15 → 0.18. 궁 타겟은 항상 적 위치. 궁 미사일은 몸 그림(한 틱 늦음) 대신 물리엔진 + 발사구 7에서 생성.
- 동일 캐릭터 대전: 1P 능력만 읽고 else 쪽에서 2P 오브젝트를 다루는 오브젝트(미사일·폭격표식 등 16개)도 소유자별로 분리.
