# 바운스어택 원본 · 34명 캐릭터 코드 해설

분석 기준은 원본 파일의 실행 블록이다. 설명 목록은 기술 이름과 원래 의도를 확인하는 보조 자료로만 사용한다. 35번째 항목 `0`은 빈 자리라 제외했다. 코드로 확정되는 값과 여러 동작을 조합해 산출해야 하는 범위를 구별했다. 실제 시간 단위와 최대 누적 피해는 반복 중단·명중 위치·기절·자원·동시 실행에 따라 달라지므로 틱과 조건식을 함께 기록한다.

핵심: 키 E=기본 공격, R=스킬, S=궁극기를 1P 기준으로 설명한다. MP 비용 표는 **각 분기의 개별 차감값**이며 표에 두 값이 있다고 합산 비용이라는 뜻은 아니다. 복제본의 모드 분기나 두 손/두 번 공격은 조건을 만족할 때만 합산된다.

## 먼저 읽을 공통 규칙

1. 피해 함수 `func_qy83`은 2P에게, `func_05j0`은 1P에게 적용한다. 첫 인자는 음수 피해, 두 번째 인자는 피격 표시 카운터, 세 번째는 화면 진동 분기다. 두 번째 인자를 무적 시간이나 연속 타격 제한으로 읽으면 안 된다.
2. 보통 피해의 크기는 `−기본인자 × 대상 피해감소량 × 대상 추가받는피해`. 방어력은 먼저 소모되는 보호막이다. 브루크는 즉시 HP 감소 대신 지연 피해에 누적하는 예외 분기를 탄다.
3. `이동속도`는 분모다. 수평 가속은 입력 때 ±0.8, 이동 상태에 ×0.96 감쇠, 실제 변위는 `좌우 / (이동속도+회전검슬로+도끼슬로+도끼부스트)`다. 기준 15에서 부스트 −6이면 분모 9로 빨라진다.
4. 몸/무기/투사체의 크기, 회전 중심, 모양 선택, 생성 오프셋, 매 반복 이동, 유효 시간, 검사 순서를 합쳐 사거리가 결정된다. 중심거리 검사는 상대 반지름을 자동으로 더하지 않는다.
5. 스프라이트 접촉 검사와 중심거리 검사는 다른 판정이다. 공개 엔진의 스프라이트 접촉은 픽셀 충돌을 사용하고 대상의 보이는 복제본도 검사한다. 따라서 원작 본체의 잔상 복제본까지 영향을 줄 수 있는지 따로 보아야 한다.
6. 블록이 시작 이벤트 없이 따로 놓여 있으면 현재 자동 실행 경로에서 제외했다. 기술 설명에 있으나 실행 근거가 약한 내용은 의도로 구분한다.

공통 피해·이동의 근거 객체: 배경〔m9cz〕, 1P 물리엔진〔00h9〕, 1player〔n230〕, 체력 바〔tw3p〕, 마나 바〔22xr〕, 타격 함수〔qy83/05j0〕.

공개 엔진 확인: [크기 계산](https://github.com/entrylabs/entryjs/blob/develop/src/class/entity.js), [접촉 검사](https://github.com/entrylabs/entryjs/blob/develop/src/playground/blocks/block_judgement.js). 현재 공개 소스 기준이며 `.ent` 안에는 실행 엔진 버전이 포함되지 않는다.

## 01. 브랜드 — 화염술사

폭발 반경과 명중 시점이 피해를 바꾸는 지연 폭발형 원거리 캐릭터.

### 기본 공격 E · 화염구

화염구는 직접 닿으면 기본 피해 7. 빗나간 뒤 커지는 폭발은 (80−현재 크기)/8 피해를 처음 닿은 순간 한 번 적용한다. 크기가 커질수록 이 식의 피해는 작아지므로 화면 끝까지 커진 폭발을 맞는 것과 초기에 맞는 것이 다르다.

### 스킬 R · 폭발표식

상대의 현재 위치에 표식을 생성한 뒤 45회 성장한다. 폭발 크기는 20에서 145로 수렴하며 피해는 (150−현재 크기)/10이다. 표식이 생긴 뒤 상대를 계속 추적하는 공격과 구분해야 한다.

### 궁극기 S · 운석

MP 55. 상승·낙하 동안 물리엔진의 무해중력을 직접 바꾸고, 상대나 지면에 닿은 뒤 폭발한다. 폭발 피해 식은 (180−현재 크기)/5, 폭발 크기는 200으로 수렴한다.

## 33. 성 미카엘 — 대 천사의 성위

기절한 적에게 추가 타격하고 기절을 해제하는 성 미카엘.

### 기본 공격 E · 대 천사의 검

본검 크기 28.1, 기본 피해 4. 적이 기절 상태면 기절을 지우고 7 추가 피해와 반동을 주는 코드가 있다. 설명문의 추가 피해 6과 다르다.

### 스킬 R · 천공

MP 20. 올려치기와 후속 베기 타격이 각각 4이며 기절한 상대를 맞힐 때 위의 7 추가 피해 분기가 열릴 수 있다. 단순히 8 피해 고정으로 세면 상태 연계가 사라진다.

### 궁극기 S · 대 천사의 부름
