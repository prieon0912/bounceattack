바운스어택 밸런스 패치 최종안 — 1차 테스트

모든 변경은 1P·2P에 동일하게 적용한다. 아래에 명시하지 않은 피해량·판정·스킬 효과는 유지한다.

1. 엑스

- 보호막 자연 만료 시 체력 회복: 3 → 0.
- 보호막 스킬 소모 MP: 31 → 28.
- 보호막 수치 10과 파괴 시 체력 회복 5는 유지한다.
- 보호막 파괴 원인에 따른 새로운 회복 제한은 추가하지 않는다.

목적: 도망만 다니며 체력을 복구하는 운영을 제한한다. 대신 보호막 사용 비용을 소폭 낮춰 교전 중 방어 성능을 보상한다. 평타·끌어당김·궁극기는 유지한다.

2. 데빌메이지

- 궁극기 소모 MP: 55 → 57.
- 궁극기 적중 시 MP 환급: 64 → 65.
- 궁극기 기본 피해·돌진 거리·선후딜·각성 효과는 유지한다.
- 추가 재사용 대기시간은 넣지 않는다.

목적: 초과 MP가 1 감소하여 피해량이 1 줄어들며, 궁극기 적중 실패 시의 리스크를 소모 MP 증가를 통해 증가시킨다.

3. 하란

- 단검의 자연 회수 거리 조건: 소유자와 거리 30 미만 → 45 미만.
- 단검의 적 공격 판정 거리와 비행 궤적은 유지한다.
- 피해량·순보 MP·순보 재사용 간격·공포 효과는 유지한다.

목적: 직접 단검을 주우러 갔을 때 근소한 거리 차이로 회수하지 못하는 상황만 줄인다. 투척 위치 관리와 회수 경로를 설계하는 부담은 남긴다.

주의: 변경하는 것은 ‘소유자가 단검을 회수하는 거리’뿐이다. 적중 거리나 순보 가능 조건을 함께 넓히지 않는다.

4. 프린스

- 기본 이동 분모: 20 → 17.
- 접근 시 이동 보정: −7.7 → −4.7.
  - 접근 중 최종 이동 분모 12.3은 유지한다.
  - 접근 이외의 위치 조정과 후퇴 성능을 개선한다.
- R 준비 구간: 25회 → 15회.
  - 단순히 반복 횟수만 줄이지 말고, 준비 동작의 이동 궤적도 새 시간에 맞춰 조정한다.
- R이 실제로 적중하면 짧은 에어본을 추가한다.
  - 공격 1회당 최초 적중 시 한 번만 적용.
  - 상승 충격량은 일반 점프 초기 상승량의 약 50%를 시작값으로 사용한다.
  - 추가 행동 제한은 0.15초.
  - 기존 수평 끌어당김은 유지하고, 별도 수평 밀치기는 추가하지 않는다.
  - 이미 걸려 있는 더 긴 제어 효과를 짧게 덮어쓰거나 해제하지 않는다.
- R 피해 11과 소모 MP 25는 유지한다.

목적: 끌어온 상대에게 공격을 성립시키기 쉽게 하고, 근접 스킬을 맞혔을 때 짧은 제어 보상을 준다. 평타에는 이번 에어본을 적용하지 않는다.

5. 스모크

- 일반 독의 주기당 피해 1, 강화 독의 주기당 피해 3은 유지한다.
- 독 피해 주기·안개 범위·안개 지속시간·둔화는 유지한다.
- 일반 평타 포션이 적에게 직접 충돌했을 때만 추가 피해 3을 한 번 적용한다.
  - 기존 폭발 피해를 별도로 올리는 변경이 아니다.
  - 바닥에 떨어진 뒤 폭발 범위만 닿은 경우에는 추가 피해를 주지 않는다.
  - 같은 포션으로 추가 피해가 중복 적용되지 않게 한다.
- 중독 적용 시 일반 독/강화 독의 피해 종류를 대상에게 기록한다.
  - 궁극기가 끝나도 이미 적용된 강화 독은 남은 중독 횟수 동안 해당 피해를 유지한다.
  - 안개 여러 개가 겹쳐도 같은 소유자의 독 피해를 무제한 중첩시키지 않는다.

목적: 범위·지속 공격의 특성을 유지하면서, 1대1에서 포션을 정확히 맞힌 경우의 보상을 소폭 높인다. 지속 피해를 두 배로 올리는 변경은 하지 않는다.

6. 테슬라

- 평타 발사 전 준비 시간: 70 → 55.
- 일반 공격과 세 번째 강화 공격에 해당하는 준비 분기에 동일하게 적용한다.
- 준비 진행값과 무기 위치 보정도 새 준비 시간에 맞춰 조정한다.
- 발사 후 대기 구간은 이번에 줄이지 않는다.
- 일반·강화 피해량, 속박 대상 추가 피해, 최대 체력 0.8배, 표식·속박 효과는 유지한다.

목적: 단발 화력을 올리지 않고, 공격 기회를 잡았을 때 긴 준비 때문에 놓치는 부담을 줄인다.

검증할 사항

- 엑스가 보호막 만료만 반복해서는 체력을 회복하지 않는지.
- 데빌메이지가 궁 적중 시 사용 전 MP로 돌아오고, 빗나가면 55를 그대로 잃는지.
- 하란의 회수 편의만 개선되고 투척·회수 반복 공격이 새로 생기지 않는지.
- 프린스 R의 찌르기 위치가 어긋나지 않고, 에어본이 공격당 한 번만 적용되는지.
- 스모크의 포션 직격 추가 피해와 기존 폭발 피해가 의도대로 구분되는지.
- 테슬라의 준비 단축이 발사 후 대기나 강화 공격 순서를 바꾸지 않는지.
- 모든 변경이 동일 캐릭터 대전에서도 소유자별로 독립적으로 작동하는지.
