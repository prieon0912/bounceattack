# 이식 기준과 변경 원칙

- 분석 원본: 사용자가 제공한 `.ent`를 작업 시작 시 동결한 스냅샷. 이전에 만든 중복 선택 수정본은 분석 원본으로 사용하지 않는다.
- 현재 그림·소리는 먼저 재사용한다. 앞으로 그림은 전부 교체할 수 있다.
- 그림을 바꿔도 사거리·피격 범위·기술 피해·동작 시간은 바뀌지 않도록 게임 규칙과 표현을 분리한다.
- 모든 캐릭터는 동일 캐릭터 대전이 가능하도록 플레이어·공격·발사체·설치물에 소유자 식별자를 가진다.
- 향후 각 캐릭터의 대체 스킬·대체 궁극기 중 하나를 선택하는 장비/선택 구성을 지원한다. 실제 선택 정책과 대체 기술 내용은 아직 정하지 않았다.
- 기본 공격, 스킬 슬롯, 궁극기 슬롯, 선택 가능한 기술 정의, 패시브를 분리한다. ‘현재 스킬=0/1/2’ 같은 모든 기술 공유 전역 변수는 사용하지 않는다.
- 수정하기 쉽게 기본 능력치, 비용, 선딜·유효시간·후딜, 타격 범위, 투사체 속도/수명, 상태 효과, 형태별 보정을 데이터로 둔다.
- 코드 기준 원작 동작과 앞으로 개선할 동작을 구별한다. 오래된 설명문이나 분리된 미실행 블록을 원작 정본으로 승격하지 않는다.
- 이번 산출물은 역분석 문서와 데이터이며 신규 게임 구현·배포·밸런스 수정을 하지 않는다.
